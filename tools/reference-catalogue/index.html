Tile geometry and source registration

The transparent PNGs carry the hex shape themselves. Tile groups use the same tile files and game lattice as the assembled map. Features that cross a hex edge remain distributed across their neighbouring tiles. The boundary row is available as a separate filter.

Terrain labels describe visible material and features. The source painting does not establish original PULSE terrain IDs or recover independent building, road and ground layers. Enlarged exports resample the supplied reference; they add no source detail.
