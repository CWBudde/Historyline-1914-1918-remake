Full-screen artwork candidates

20 screen-state studies in the existing slate/brass vocabulary. All labels and example values below are live HTML. Controls demonstrate artwork states; they perform no gameplay, saving, campaign unlocking or editor operations. These are fixed 640×400 layout studies. Native font composition, responsive layouts, keyboard flows and runtime acceptance require review.

The painted backdrop is retained at 1×/2× only: its source cannot support a true 4× export. Text-free vector frames and five shared button states have 1×/2×/4× PNGs and editable SVGs. Saved 2× compositions are review fixtures only, never runtime artwork. Handover uses an opaque frame and loads no backdrop.
