Cell layers

Draw order: terrain → infrastructure → units → markers. Terrain and unit placement replace that layer; infrastructure and markers can be stacked. Offsets adjust a piece without moving its cell. Shrinking preserves cells still inside the grid.

Placement and saving

Building templates use the current compound exporter’s exact relative positions. The staggered map uses 142 px column pitch, 71 px odd-row offset and 40 px line pitch. Tiles are 96 × 80; units are 96 × 96 with their (48,49) anchor on the tile’s (48,40) center.

Edits are saved locally in this browser when storage is available. Export JSON to keep a portable copy of your collection. Collections contain asset IDs and placements; they do not contain artwork. Import validates every ID, variant and grid position before replacing the open collection. JSON remains usable after regenerating this review bundle with the same asset IDs.

These are visual review scenes made from retained default-context exports. Arbitrary neighbor context, world-phase matching, legal unit placement and runtime acceptance are not resolved here. Reference units keep their base pose/palette at the old 96 px game footprint. Missing reference layers stay empty; reference images never replace missing current artwork.
