01 / ORIGINAL DOS AND CURRENT ART

Original DOS ground, current renderings

The reference is decoded directly from the supplied DOS terrain library, palette and FIN map. Roads and paths are part of those original tiles. Its aligned view uses nearest-neighbour geometry normalization for comparison; the native view retains the original 24×24 tile pixels. Current 2×/4× sources use authored exports and the shared runtime context selector; 1× is a Lanczos reduction of the 2× composition.

Sources, reference limits and composition gaps

The DOS reference is ground-only: no units, ownership strips or UI. Current terrain/infrastructure is selected by default for comparison; current units can be enabled independently. The aligned DOS view rescales the complete ground lattice without smoothing to match cell centres. Original hex outlines still differ from the remake’s. Remaining original forbidden border cells stay visible, including the lower boundary that differs from the remake. Both native views are static ground reconstructions, not executed DOS/Amiga game captures.
