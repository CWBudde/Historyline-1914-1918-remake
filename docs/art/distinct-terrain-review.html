Distinct illustrated terrain pack

Twelve newly authored terrain sources. Natural continuous contours, muted sage greens, overhead view, and Lanczos3 exports. Batch 01 review · Batch 02 review · Runtime coverage · Manifest

Candidates with rectangular overscan. Shared forest scale, hex clipping, runtime ID mapping and adjoining hex seams remain open. These are new illustrations; original graphics and earlier reconstruction studies are excluded from this manifest.
